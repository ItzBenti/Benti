# Datenschutzerklärung – Benti

Stand: 13.11.2026

## Kurzfassung
Benti verarbeitet alle Bilder ausschließlich lokal in Ihrem Browser. Es werden **keinerlei Daten erhoben, gespeichert oder übertragen**.

## Im Einzelnen

- **Bilder:** Alle geladenen Bilder werden ausschließlich im Arbeitsspeicher Ihres Browsers verarbeitet. Es findet kein Upload auf Server statt; die Erweiterung stellt keinerlei Netzwerkverbindungen her.
- **Einstellungen:** Ihre Einstellungen (z. B. Label-Typ, Deckkraft, Position) werden über die Chrome-Storage-API lokal in Ihrem Browserprofil gespeichert. Sie verlassen Ihr Gerät nicht.
- **Compliance-Protokoll (sofern aktiviert):** Das Kennzeichnungs-Verzeichnis (Zeitstempel, Datei-Hashes, Label-Typ) wird ausschließlich lokal in Ihrem Browserprofil gespeichert. Bildinhalte werden nie protokolliert. Sie können das Protokoll jederzeit exportieren oder vollständig löschen.
- **Keine Telemetrie:** Es gibt keine Analyse-, Tracking- oder Absturzberichts-Funktionen.
- **Keine Konten:** Die Nutzung erfordert keine Registrierung.
- **Downloads:** Gekennzeichnete Bilder werden über die Chrome-Downloads-API in Ihren lokalen Download-Ordner gespeichert.
- **Eigener Ablageordner (sofern gewählt):** Wählen Sie einen eigenen Speicherordner, merkt sich der Browser lediglich die von Ihnen erteilte Ordner-Freigabe lokal in Ihrem Browserprofil. Sie können sie jederzeit in den Browser-Einstellungen widerrufen.
